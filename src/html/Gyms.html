Gyms near and around Sydney

Climb Fit

-Price: Day pass $25 ($22 concession, $21 kids), plus gear hire if needed
-Grading: Number system (1-10)
-Locations: Macquarie Park, St Leonards, Kirrawee

Climb Fit Website

Pulse Climbing

-Price: Casual entry $24 ($21 concession, $19 child), $49 two-week trial for newcomers
-Grading: Number system (1-10)
-Locations: Gosford, Adamstown, Warners Bay, Maitland

Pulse Climbing Website

BlocHaus

-Price: Day pass $26 ($24 concession), memberships from $38/week
-Grading: Colour-coded per hold rather than numbered V-grades
-Locations: Marrickville, Leichhardt, Fyshwick, Mitchell, Port Melbourne

BlocHaus Website

9 Degrees

-Price: Day pass $25, memberships from $28/week
-Grading: Standard V-scale, V0 through V12+
-Locations: Alexandria, Waterloo, Lane Cove, Chatswood, Parramatta, Morningside, Enoggera

9 Degrees Website

-Price: Website has a price calculator
-Grading: No grading system published online
-Locations: St Peters, Villawood

NOMAD Bouldering

-Price: Day pass $26 ($24 student), memberships from $30/week
-Grading: Coloured tags at the start of each climb
